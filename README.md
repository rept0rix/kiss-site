# KISS site

Standalone marketing landing page for KISS PWA.

Throw a kiss at someone. That is the whole app.

## Stack

- Vite + vanilla HTML/CSS/JS
- No auth, no database

## Local

Install packages, then start the Vite dev server.
Production build writes to dist/. Preview the production build with the preview script.

## Environment

VITE_APP_URL sets the Open KISS CTA href. Fallback: #app. See .env.example.

## Brand

Black / blood-red. Archivo Black. Mobile-first game vibe.

## Scripts

- dev — local Vite server
- build — production output to dist/
- preview — serve dist/
